8-week plan

This is the compressed track: 8 weeks, calibrated for someone with a competitive-programming background where raw DSA isn't the gap — pattern recognition under interview conditions and company-specific depth are. Every week has a problem-count target and points to the exact resource to use that week, plus a priority legend so you know what's non-negotiable if time runs short.

8 weeks ~120 problems 6 platform resources
Must-do before any interview: monotonic stack, graph BFS/DFS, LRU cache, Spring Cloud resilience, thread-safe Java
High leverage: DP on trees, topological sort, Dijkstra, CompletableFuture, virtual threads
Good to have: segment trees, advanced trie, Spring Boot security, math/geometry

Foundation patterns
